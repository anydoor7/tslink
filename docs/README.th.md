<h1 align="center">TSLink</h1>
<p align="center"><strong>ให้แต่ละแอปบนคอมพิวเตอร์หรือเซิร์ฟเวอร์ของคุณมีที่อยู่ส่วนตัวของตัวเองในเครือข่าย Tailscale ของคุณ และกำหนดเองได้ว่าใครเข้าถึงได้</strong></p>

เปิดเว็บแอป โฟลเดอร์ API โมเดล และฐานข้อมูลของคุณจากโทรศัพท์และแล็ปท็อปของคุณเอง พร้อมการตรวจสุขภาพและประวัติการเข้าถึงของแต่ละแอป เอเจนต์ AI ของคุณกำหนดที่อยู่ส่วนตัวให้แอปที่ตัวเองเปิดบน localhost เพื่อให้อุปกรณ์อื่นของคุณเปิดได้ และตรวจสอบแอปเหล่านั้นได้ ภายในบทบาทที่คุณให้ไว้ เมื่อคนอื่นต้องเข้าใช้ ให้สิทธิ์บุคคลที่ระบุไว้จนถึงวันที่กำหนด หรือเปิดเว็บแอปสู่อินเทอร์เน็ตสาธารณะเป็นเวลาจำกัด

**ต้องใช้ Tailscale** คุณต้องมีบัญชี Tailscale (ใช้ส่วนตัวฟรี) และทุกอุปกรณ์ที่เปิดแอปส่วนตัวต้องมีแอป Tailscale ส่วนผู้เยี่ยมชมและผู้เข้าชมสาธารณะใช้แค่เบราว์เซอร์ TSLink เป็นโครงการอิสระ ไม่ได้สร้างหรือรับรองโดย Tailscale [ข้อกำหนด](#requirements)

## สิ่งที่คุณทำได้

### เข้าถึงแอปของคุณเอง

- **แอปละหนึ่งที่อยู่** `tslink share 3000`, `tslink share ./photos` หรือ `tslink add db --tcp localhost:5432` ให้เว็บแอป โฟลเดอร์ ไฟล์ หรือบริการ TCP มีที่อยู่ส่วนตัวของตัวเองใน tailnet ของคุณ (เครือข่าย Tailscale ส่วนตัวของคุณ) เช่น `https://photos.<tailnet>.ts.net` แต่ละแอปเป็นอุปกรณ์ Tailscale แยกกัน คุณจึงเปิดแอปด้วยชื่อแทนการใช้ที่อยู่ IP และพอร์ต
- **เป็นส่วนตัว เว้นแต่คุณเลือกเป็นอย่างอื่น** TSLink ให้การเข้าถึงแอปเป็นแบบส่วนตัวโดยค่าเริ่มต้น และนโยบาย tailnet ของคุณเป็นตัวกำหนดว่าอุปกรณ์ใดเชื่อมต่อได้ TSLink จะเปิดปลายทางสาธารณะของแอปเฉพาะเมื่อคุณสร้างลิงก์ผู้เยี่ยมชมหรือเผยแพร่ผ่าน Funnel อย่างชัดแจ้งเท่านั้น
- **ดูทั้งหมดได้ในที่เดียว** `tslink status --urls` แสดงแอปที่ลงทะเบียนไว้บนคอมพิวเตอร์เครื่องนี้ และหน้าแรกส่วนตัวซึ่งเลือกเปิดใช้ได้จะแสดงที่อยู่และสถานะของแอปเหล่านั้น [พอร์ทัล](portal.md)
- **รู้ทันทีเมื่อมีอะไรเสีย** การตรวจสุขภาพเบื้องหลังแจ้งเตือนคุณผ่านคำสั่งหรือ webhook ได้เมื่อแอปล่มหรือกลับมาทำงาน หรือเมื่อการลงชื่อเข้าใช้ Tailscale ของแอปใกล้หมดอายุ ประวัติการเข้าถึงแสดงว่าใครเปิดแอปใดเมื่อไร รวมถึงคำขอที่ถูกปฏิเสธ [สุขภาพและการแจ้งเตือน](health-and-alerts.md) · [ประวัติการเข้าถึง](access-log.md)
- **สูตรสำหรับแอป** มีสูตรสำหรับแอปที่โฮสต์เอง 15 ตัว รวมถึง Home Assistant, Jellyfin, Immich และ Ollama ส่วน `tslink apps detect` ค้นหาแอปที่รองรับซึ่งรอรับการเชื่อมต่ออยู่ในเครื่องแล้วได้ หากต้องอัปโหลดรูปภาพและวิดีโอขนาดใหญ่ ให้[เพิ่มขีดจำกัดการอัปโหลดของแต่ละแอป](sharing.md) [สูตรตั้งค่าแอป](apps.md) · [AI ในเครื่อง](local-ai.md)

### ให้เอเจนต์ทำงานกับแอปเหล่านี้

เมื่อเอเจนต์เปิดเซิร์ฟเวอร์สำหรับพัฒนา หน้าพรีวิว หรือ API โมเดลในเครื่องบน `localhost` โทรศัพท์และคอมพิวเตอร์เครื่องอื่นของคุณจะเข้าถึงที่อยู่นั้นไม่ได้ TSLink ช่วยให้เอเจนต์กำหนดที่อยู่ส่วนตัวให้ บอก URL ที่แน่นอนให้คุณ และยกเลิกการลงทะเบียนอีกครั้ง ภายในขอบเขตที่คุณกำหนด

- **แชร์ ตรวจสอบ ยกเลิก** `share --json` ส่งคืนชื่อที่ลงทะเบียนไว้ พร้อม URL ที่แน่นอนหรือลิงก์ลงชื่อเข้าใช้ให้คุณเปิด `url <name> --wait` และ `status --urls --name <name>` บอกว่าปลายทางพร้อมแล้วหรือยัง และ `remove <name>` (ใน MCP คือ `unshare`) ลบการแชร์ออก [คู่มือเอเจนต์](agent-quickstart.md)
- **ออกแบบมาเพื่องานอัตโนมัติ** คำสั่งจัดการทั้งหมดยกเว้น `tslink mcp` รองรับ `--json` และส่งคืนผลลัพธ์ที่มีเวอร์ชันพร้อมรหัสข้อผิดพลาดที่คงที่ `tslink mcp` ให้เครื่องมือด้านแอปและการเข้าถึงกับไคลเอนต์ MCP ในเครื่องผ่าน JSON-RPC เมื่อกำหนดการผูกผู้เรียกไว้แล้ว `tslink serve --mcp` จะให้เครื่องมือเหล่านั้นกับไคลเอนต์ MCP บนอุปกรณ์อื่นของคุณผ่าน tailnet [JSON อัตโนมัติ](json-automation.md) · [MCP ระยะไกล](remote-mcp.md)
- **อำนาจจำกัด** เอเจนต์ในเครื่องมีอำนาจระดับเจ้าของโดยค่าเริ่มต้น ให้บทบาทที่ลดลงแก่เอเจนต์ (`viewer`, `app-operator` หรือ `people-manager`) ซึ่งครอบคลุมเฉพาะแอปที่คุณระบุ และจำกัดระยะเวลาสูงสุดของสิทธิ์ที่เอเจนต์มอบให้ การเปลี่ยนแปลงผ่าน MCP จะถูกบันทึก และ `tslink mcp-audit` แสดงรายการเหล่านั้น บทบาทจำกัดเครื่องมือของ TSLink เท่านั้น ไม่ได้จำกัดเชลล์หรือไฟล์ของเอเจนต์เอง [สิทธิ์ MCP](mcp-scopes.md)

### แชร์กับคนที่คุณเลือก

- **บุคคลที่ระบุ จนถึงวันที่กำหนด** `tslink people add alice@example.com --apps photos,notes --for 7d` ให้บัญชี Tailscale นั้นเปิดเว็บแอปและแอปไฟล์เหล่านั้นได้จนถึงกำหนด `people update`, `extend` และ `people remove` ใช้เปลี่ยนหรือยุติสิทธิ์ หลังลบออก คำขอถัดไปของคนนั้นจะถูกปฏิเสธ แต่เรียกคืนสิ่งที่ดาวน์โหลดไปแล้วไม่ได้ [บุคคล](people.md) · [ระยะเวลา](durations.md)
- **คนที่อยู่นอก tailnet ของคุณ** เพิ่ม `--invite --print-links` เพื่อรับข้อความเดียวที่พร้อมส่ง ซึ่งมีคำเชิญอุปกรณ์สำหรับแต่ละแอป (ต้องใช้โทเค็น API ที่ผู้ใช้เป็นเจ้าของ) `--qr` พิมพ์โค้ดสำหรับตั้งค่าบนโทรศัพท์
- **คำขอ** คนใน tailnet ของคุณขอเวลาเพิ่ม หรือขอใช้แอปที่คุณตั้งให้ขอได้ จากหน้าแรก คุณอนุมัติพร้อมกำหนดระยะเวลาได้ในคำสั่งเดียว [คำขอเข้าถึง](requests.md)

### เปิดเว็บแอปสู่อินเทอร์เน็ตชั่วคราว

- **ลิงก์ผู้เยี่ยมชม** `tslink guest create photos --for 3d --public --print-link` สร้างลิงก์เบราว์เซอร์ไปยังเว็บแอปหนึ่งตัว จะใส่ PIN ก็ได้ และเพิกถอนแยกเป็นรายลิงก์ได้ ผู้เยี่ยมชมไม่ต้องมีบัญชี Tailscale ใครก็ตามที่มีลิงก์ใช้ได้ จึงพิสูจน์ไม่ได้ว่าใครเป็นผู้เข้าชม [ลิงก์ผู้เยี่ยมชม](guest-links.md)
- **URL สาธารณะแบบเปิด** `tslink add preview --proxy localhost:3000 --funnel --public` เผยแพร่เว็บแอปให้ทุกคนที่มี URL การเผยแพร่ใหม่มีอายุ 24 ชั่วโมงโดยค่าเริ่มต้น ใช้ `--funnel-ttl` เพื่อเลือกอายุอื่น [Funnel](funnel.md)
- ลิงก์ผู้เยี่ยมชมใหม่และการเผยแพร่สาธารณะแบบเปิดใหม่ทำงานผ่าน Tailscale Funnel และมีอายุจำกัด (อย่างน้อย 1 ชั่วโมง สูงสุดตามค่าเริ่มต้น 7 วัน เจ้าของปรับได้) เส้นทางสาธารณะเหล่านี้รองรับแอปแบบ HTTP proxy ส่วนบริการโฟลเดอร์หรือไฟล์ที่ให้บริการโดยตรงและ TCP แบบดิบยังคงเป็นส่วนตัว

ทั้งหมดข้างต้นมาพร้อม v0.1.0

## ข้อกำหนด

TSLink สร้างขึ้นบน Tailscale เป็นโครงการอิสระ ไม่ได้สร้างหรือรับรองโดย Tailscale และอยู่ภายใต้ข้อกำหนดและ[แพ็กเกจ](https://tailscale.com/pricing)ของ Tailscale เอง

| ใคร | ต้องมีอะไร |
|---|---|
| คุณ | บัญชี Tailscale ที่เปิด [MagicDNS และ HTTPS](https://tailscale.com/docs/how-to/set-up-https-certificates) แล้ว แพ็กเกจ Personal ฟรีใช้ได้เฉพาะงานที่ไม่ใช่เชิงพาณิชย์ |
| คอมพิวเตอร์หรือเซิร์ฟเวอร์ที่รันแอปของคุณ | TSLink อย่างเดียว มี Tailscale ฝังอยู่ในตัว จึงไม่ต้องติดตั้ง Tailscale แยก เมื่อใช้การตั้งค่าเริ่มต้น โหนดแอปใหม่แต่ละตัวต้องลงชื่อเข้าใช้ผ่านเบราว์เซอร์ และอาจต้องได้รับการอนุมัติอุปกรณ์ [ข้อมูลรับรองที่จัดเก็บไว้](credentials-and-tags.md) ช่วยให้ลงทะเบียนได้โดยไม่ต้องลงชื่อเข้าใช้ผ่านเบราว์เซอร์ทีละแอป |
| อุปกรณ์อื่นของคุณ | แอป Tailscale ที่ลงชื่อเข้าใช้ tailnet ของคุณแล้ว |
| คนที่คุณเลือก | แอป Tailscale และบัญชีของเขาเอง จะเข้าร่วม tailnet ของคุณ ซึ่งเพิ่มผู้ใช้หนึ่งคนในแพ็กเกจของคุณ หรือรับคำเชิญอุปกรณ์สำหรับแต่ละแอปก็ได้ นโยบาย tailnet ของคุณต้องอนุญาตให้เขาเข้าถึง |
| ผู้เยี่ยมชมและผู้เข้าชมสาธารณะ | เบราว์เซอร์ และ tailnet ของคุณต้องอนุญาต Funnel ซึ่ง Tailscale ยังจัดเป็นเบต้า |

เมื่อมีการออกใบรับรอง HTTPS ให้แอป ชื่ออุปกรณ์ Tailscale ของแอปนั้นและชื่อ DNS ของ tailnet ของคุณจะปรากฏในบันทึกใบรับรองสาธารณะ ควรตั้งชื่อแอปที่คุณไม่ว่าอะไรหากคนอื่นเห็น

## เริ่มต้นอย่างรวดเร็ว

บน macOS และ Linux ให้ติดตั้งด้วย Homebrew ไบนารีสำหรับ macOS ลงนามด้วยใบรับรอง Developer ID และผ่านการ notarize โดย Apple เมื่อจะอัปเกรดในภายหลัง ให้รัน `brew upgrade --cask tslink` แล้วรัน `tslink install` อีกครั้งหาก TSLink ทำงานเป็นบริการเบื้องหลัง

```bash
brew install --cask anydoor7/tap/tslink
```

บน Windows ให้ดาวน์โหลด `tslink_<version>_windows_<arch>.zip` จาก[รุ่นล่าสุด](https://github.com/anydoor7/tslink/releases/latest) ตรวจสอบกับ `checksums.txt` แล้วรัน `tslink install` เพื่อให้ TSLink เริ่มทำงานเมื่อลงชื่อเข้าใช้ ไฟล์ zip ไม่ได้ลงนามด้วย Authenticode จึงควร[ตรวจสอบรุ่นที่เผยแพร่](verify-release.md)ผ่าน checksum ที่ลงนามแล้วและ attestation แพ็กเกจ `.deb` และ `.rpm` สำหรับ Linux อยู่ในหน้ารุ่นเดียวกัน หากต้องการคอมไพล์จากซอร์ส ต้องใช้ **Git และ Go 1.26.6+** คำสั่งด้านล่างใช้ bash/zsh ดู[การตั้งค่า macOS, Linux และ Windows](platforms.md)

```bash
git clone https://github.com/anydoor7/tslink.git
cd tslink
go install .
export PATH="$PATH:$(go env GOPATH)/bin"
```

คุณต้องมี **บัญชี Tailscale** และ [MagicDNS กับ HTTPS](https://tailscale.com/docs/how-to/set-up-https-certificates) อุปกรณ์ที่เข้าถึงแบบส่วนตัวต้องใช้ Tailscale และได้รับอนุญาตตามนโยบายเครือข่าย TSLink ฝัง Tailscale ไว้บนโฮสต์ของแอป

เมื่อแอปทำงานอยู่ที่พอร์ต 3000 แล้ว:

```bash
tslink share 3000 --name myapp
tslink url myapp --wait
```

เลือกชื่อที่ยังไม่ถูกใช้ หาก `share` คืนชื่ออื่น ให้ใช้ชื่อนั้นกับ `url` ทำการลงทะเบียนผ่านเบราว์เซอร์และอนุมัติอุปกรณ์ตามที่แจ้งก่อน แล้วเปิด URL แอปที่ได้รับจริงบนอุปกรณ์ที่อนุญาต `share` เริ่มบริการเบื้องหลังเมื่อจำเป็น การใช้แบบส่วนตัวครั้งแรกนี้ไม่ต้องมีโทเค็น API ผู้ดูแล แชร์ไฟล์ด้วย `tslink share ./report.html` โดยไฟล์ต้องมีอยู่และแอปต้องทำงานแล้ว [การตั้งค่าฉบับเต็ม](getting-started.md)

เมื่อใช้งานได้และมีประโยชน์ คุณอาจ[ให้ดาว TSLink](https://github.com/anydoor7/tslink) เพื่อช่วยให้คนอื่นค้นพบ ทั้งหมดเป็นความสมัครใจ

ให้นึกถึงเส้นทางส่วนตัวที่เข้ารหัสไปยังแอปของคุณ **Tailscale ให้การรับส่งเครือข่ายและ HTTPS ส่วน TSLink จัดการสิทธิ์เข้าแอปในแต่ละโฮสต์** เดมอนหนึ่งตัวรันโหนดฝังตัวแยกสำหรับแต่ละบริการ พอร์ทัลส่วนตัวแสดงแอปที่อนุญาต พร้อมสถานะสุขภาพและประวัติที่ช่วยดูแลระบบ

การเข้าถึงสาธารณะต้องเลือกเปิด: ผู้เยี่ยมชมต้องมีลิงก์และ PIN หากตั้งไว้ ส่วน Funnel แบบเปิดเข้าถึงได้โดยทุกคนที่มี URL ทั้งสองใช้ HTTPS สาธารณะ ไม่ใช่ตัวตนผู้ใช้แบบส่วนตัว TCP ดิบยังคงเป็นส่วนตัวและขึ้นกับนโยบาย tailnet กับการยืนยันตัวตนของแบ็กเอนด์ TSLink ไม่ติดตั้งแอป ไม่แยกกระบวนการ ไม่สร้าง VPC คลาวด์ และไม่รวมหลายโฮสต์ เป็นโครงการอิสระที่ทำงานร่วมกับ Tailscale [สถาปัตยกรรมและขอบเขต](architecture.md)

## สำหรับเอเจนต์

จัดการรายการ สุขภาพ URL และสิทธิ์ผ่าน CLI/MCP เริ่มจาก[คู่มือเอเจนต์](agent-quickstart.md) อ่านสคีมาของเครื่องมือปัจจุบัน และตรวจสอบการเข้าแอปจริงก่อนรายงานความสำเร็จ

```json
{"mcpServers":{"tslink":{"command":"tslink","args":["mcp"]}}}
```

ระบบอัตโนมัติ CLI ใช้ `--json` ส่วน MCP ใช้ JSON-RPC ผ่าน stdio [ไคลเอนต์](mcp-clients.md) · [MCP ระยะไกล](remote-mcp.md) · [บทบาทและขอบเขต](mcp-scopes.md)
