<h1 align="center">TSLink</h1>
<p align="center"><strong>Δώστε σε κάθε εφαρμογή στον υπολογιστή ή στον διακομιστή σας τη δική της ιδιωτική διεύθυνση στο δίκτυο Tailscale σας και αποφασίστε ποιος μπορεί να τη φτάσει.</strong></p>

Ανοίξτε τις εφαρμογές web, τους φακέλους, τα API μοντέλων και τις βάσεις δεδομένων σας από το δικό σας κινητό και φορητό υπολογιστή, με έλεγχο υγείας και ιστορικό πρόσβασης για καθεμία. Οι πράκτορες AI σας μπορούν να αποδίδουν στις εφαρμογές που ξεκινούν στο localhost μια ιδιωτική διεύθυνση για τις άλλες συσκευές σας και να τις ελέγχουν, μέσα στον ρόλο που τους δίνετε. Όταν κάποιος άλλος χρειάζεται πρόσβαση, δώστε πρόσβαση σε ένα συγκεκριμένο άτομο έως μια ημερομηνία ή ανοίξτε μια εφαρμογή web στο δημόσιο διαδίκτυο για περιορισμένο χρόνο.

**Απαιτεί Tailscale.** Χρειάζεστε λογαριασμό Tailscale (δωρεάν για προσωπική χρήση), και κάθε συσκευή που ανοίγει μια ιδιωτική εφαρμογή χρειάζεται την εφαρμογή Tailscale. Οι επισκέπτες και το δημόσιο κοινό χρειάζονται μόνο πρόγραμμα περιήγησης. Το TSLink είναι ανεξάρτητο έργο, που δεν έχει φτιαχτεί ούτε εγκριθεί από την Tailscale. [Απαιτήσεις](#requirements)

## Τι μπορείτε να κάνετε

### Πρόσβαση στις δικές σας εφαρμογές

- **Μια διεύθυνση για κάθε εφαρμογή.** Οι εντολές `tslink share 3000`, `tslink share ./photos` ή `tslink add db --tcp localhost:5432` δίνουν σε μια εφαρμογή web, φάκελο, αρχείο ή υπηρεσία TCP τη δική της ιδιωτική διεύθυνση στο tailnet σας (το ιδιωτικό σας δίκτυο Tailscale), για παράδειγμα `https://photos.<tailnet>.ts.net`. Κάθε εφαρμογή είναι ξεχωριστή συσκευή Tailscale, οπότε ανοίγετε τις εφαρμογές με το όνομά τους αντί για διεύθυνση IP και θύρα.
- **Ιδιωτικές, εκτός αν επιλέξετε διαφορετικά.** Το TSLink κρατά από προεπιλογή ιδιωτική την πρόσβαση στις εφαρμογές και η πολιτική του tailnet σας αποφασίζει ποιες συσκευές μπορούν να συνδεθούν. Ανοίγει δημόσιο σημείο πρόσβασης εφαρμογής μόνο όταν δημιουργείτε σύνδεσμο επισκέπτη ή δημοσιεύετε ρητά μέσω Funnel.
- **Όλα σε ένα σημείο.** Το `tslink status --urls` εμφανίζει τις εφαρμογές που είναι καταχωρισμένες σε αυτόν τον υπολογιστή, και μια προαιρετική ιδιωτική αρχική σελίδα δείχνει τις διευθύνσεις και την κατάστασή τους. [Πύλη](portal.md)
- **Μαθαίνετε αμέσως όταν κάτι χαλάσει.** Οι έλεγχοι υγείας στο παρασκήνιο μπορούν να σας ειδοποιήσουν μέσω εντολής ή webhook όταν μια εφαρμογή πέσει ή επανέλθει, ή όταν η σύνδεσή της στο Tailscale πρόκειται να λήξει. Το ιστορικό πρόσβασης δείχνει ποιος άνοιξε ποια εφαρμογή και πότε, μαζί με τα αιτήματα που απορρίφθηκαν. [Υγεία και ειδοποιήσεις](health-and-alerts.md) · [Ιστορικό πρόσβασης](access-log.md)
- **Συνταγές εφαρμογών.** Οι συνταγές καλύπτουν 15 αυτοφιλοξενούμενες εφαρμογές, ανάμεσά τους Home Assistant, Jellyfin, Immich και Ollama, και το `tslink apps detect` μπορεί να βρει υποστηριζόμενες εφαρμογές που ήδη ακούν τοπικά. Για μεγάλες μεταφορτώσεις φωτογραφιών και βίντεο, [αυξήστε τα όρια μεταφόρτωσης της κάθε εφαρμογής](sharing.md). [Συνταγές εφαρμογών](apps.md) · [Τοπική AI](local-ai.md)

### Αφήστε τους πράκτορές σας να δουλέψουν με αυτές

Όταν ένας πράκτορας ξεκινά έναν διακομιστή ανάπτυξης, μια προεπισκόπηση ή ένα τοπικό API μοντέλου στο `localhost`, το κινητό σας και οι άλλοι υπολογιστές σας δεν μπορούν να φτάσουν σε αυτή τη διεύθυνση. Το TSLink επιτρέπει στον πράκτορα να του δώσει μια ιδιωτική διεύθυνση, να σας πει το ακριβές URL και να αφαιρέσει ξανά την καταχώρισή του, μέσα στα όρια που ορίζετε.

- **Κοινοποίηση, έλεγχος, αναίρεση.** Το `share --json` επιστρέφει το όνομα που καταχώρισε και είτε το ακριβές URL είτε έναν σύνδεσμο σύνδεσης για να τον ανοίξετε. Τα `url <name> --wait` και `status --urls --name <name>` αναφέρουν αν το σημείο πρόσβασης είναι έτοιμο, και το `remove <name>` (`unshare` στο MCP) αφαιρεί την κοινοποίηση. [Οδηγός πρακτόρων](agent-quickstart.md)
- **Φτιαγμένο για αυτοματοποίηση.** Οι εντολές διαχείρισης εκτός από το `tslink mcp` δέχονται `--json` και επιστρέφουν αποτελέσματα με έκδοση και σταθερούς κωδικούς σφάλματος. Το `tslink mcp` προσφέρει εργαλεία για εφαρμογές και πρόσβαση σε έναν τοπικό πελάτη MCP μέσω JSON-RPC. Με ρυθμισμένες αντιστοιχίσεις καλούντων, το `tslink serve --mcp` προσφέρει αυτά τα εργαλεία σε πελάτες MCP στις άλλες συσκευές σας μέσω του tailnet. [Αυτοματοποίηση JSON](json-automation.md) · [Απομακρυσμένο MCP](remote-mcp.md)
- **Περιορισμένη εξουσία.** Ένας τοπικός πράκτορας έχει από προεπιλογή εξουσία κατόχου. Δώστε σε έναν πράκτορα έναν περιορισμένο ρόλο (`viewer`, `app-operator` ή `people-manager`) που καλύπτει μόνο τις εφαρμογές που ορίζετε και βάζει ανώτατο όριο στη διάρκεια κάθε πρόσβασης που παραχωρεί. Οι αλλαγές μέσω MCP καταγράφονται, και το `tslink mcp-audit` τις εμφανίζει. Οι ρόλοι περιορίζουν τα εργαλεία του TSLink, όχι το κέλυφος ή τα αρχεία του ίδιου του πράκτορα. [Δικαιώματα MCP](mcp-scopes.md)

### Κοινή χρήση με άτομα της επιλογής σας

- **Συγκεκριμένα άτομα, έως μια ημερομηνία.** Το `tslink people add alice@example.com --apps photos,notes --for 7d` επιτρέπει σε αυτόν τον λογαριασμό Tailscale να ανοίγει αυτές τις εφαρμογές web και αρχείων έως την προθεσμία. Τα `people update`, `extend` και `people remove` αλλάζουν ή τερματίζουν την πρόσβαση. Μετά την αφαίρεση, το επόμενο αίτημα του ατόμου απορρίπτεται, αλλά όσα έχει ήδη κατεβάσει δεν ανακτώνται. [Άτομα](people.md) · [Διάρκειες](durations.md)
- **Κάποιος εκτός του tailnet σας.** Προσθέστε `--invite --print-links` για να πάρετε ένα μήνυμα έτοιμο για αποστολή, με πρόσκληση συσκευής για κάθε εφαρμογή (απαιτεί token API που ανήκει σε χρήστη). Το `--qr` τυπώνει κωδικό για ρύθμιση στο κινητό.
- **Αιτήματα.** Τα άτομα στο tailnet σας μπορούν από την αρχική σελίδα να ζητήσουν περισσότερο χρόνο ή πρόσβαση σε μια εφαρμογή που έχετε σημειώσει ως διαθέσιμη κατόπιν αιτήματος. Εγκρίνετε με μία εντολή, ορίζοντας διάρκεια. [Αιτήματα πρόσβασης](requests.md)

### Ανοίξτε μια εφαρμογή web στο διαδίκτυο, για λίγο

- **Σύνδεσμοι επισκέπτη.** Το `tslink guest create photos --for 3d --public --print-link` δημιουργεί σύνδεσμο προγράμματος περιήγησης προς μία εφαρμογή web, με προαιρετικό PIN, τον οποίο μπορείτε να ανακαλέσετε ξεχωριστά. Οι επισκέπτες δεν χρειάζονται λογαριασμό Tailscale. Όποιος έχει τον σύνδεσμο μπορεί να τον χρησιμοποιήσει, οπότε δεν αποδεικνύει ποιος μπήκε. [Επισκέπτες](guest-links.md)
- **Ανοιχτό δημόσιο URL.** Το `tslink add preview --proxy localhost:3000 --funnel --public` δημοσιεύει μια εφαρμογή web για όποιον έχει το URL της. Μια νέα δημοσίευση διαρκεί από προεπιλογή 24 ώρες, και με το `--funnel-ttl` επιλέγετε άλλη διάρκεια. [Funnel](funnel.md)
- Οι νέοι σύνδεσμοι επισκέπτη και οι νέες ανοιχτές δημόσιες δημοσιεύσεις περνούν από το Tailscale Funnel και έχουν περιορισμένη διάρκεια (τουλάχιστον 1 ώρα, έως 7 ημέρες από προεπιλογή, με όριο που ρυθμίζει ο κάτοχος). Αυτές οι δημόσιες διαδρομές υποστηρίζουν εφαρμογές μέσω HTTP proxy, ενώ οι υπηρεσίες που σερβίρουν απευθείας φακέλους ή αρχεία και το σκέτο TCP μένουν ιδιωτικά.

Όλα τα παραπάνω περιλαμβάνονται στην έκδοση v0.1.0.

## Απαιτήσεις

Το TSLink βασίζεται στο Tailscale. Είναι ανεξάρτητο έργο, που δεν έχει φτιαχτεί ούτε εγκριθεί από την Tailscale, και ισχύουν οι όροι και τα [προγράμματα](https://tailscale.com/pricing) της Tailscale.

| Ποιος | Τι χρειάζεται |
|---|---|
| Εσείς | Λογαριασμό Tailscale με ενεργοποιημένα [MagicDNS και HTTPS](https://tailscale.com/docs/how-to/set-up-https-certificates). Το δωρεάν πρόγραμμα Personal είναι για μη εμπορική χρήση. |
| Ο υπολογιστής ή ο διακομιστής που τρέχει τις εφαρμογές σας | Μόνο το TSLink. Ενσωματώνει το Tailscale, οπότε δεν χρειάζεται ξεχωριστή εγκατάσταση του Tailscale. Με την προεπιλεγμένη ρύθμιση, κάθε νέος κόμβος εφαρμογής χρειάζεται σύνδεση από το πρόγραμμα περιήγησης και ίσως έγκριση συσκευής. Με [αποθηκευμένα διαπιστευτήρια](credentials-and-tags.md) η εγγραφή γίνεται χωρίς σύνδεση από το πρόγραμμα περιήγησης για κάθε εφαρμογή. |
| Οι άλλες συσκευές σας | Την εφαρμογή Tailscale, συνδεδεμένη στο tailnet σας. |
| Άτομα της επιλογής σας | Την εφαρμογή Tailscale και τον δικό τους λογαριασμό. Είτε μπαίνουν στο tailnet σας, κάτι που προσθέτει έναν χρήστη στο πρόγραμμά σας, είτε αποδέχονται μια πρόσκληση συσκευής για κάθε εφαρμογή. Η πολιτική του tailnet σας πρέπει να τους επιτρέπει την πρόσβαση. |
| Επισκέπτες και δημόσιο κοινό | Ένα πρόγραμμα περιήγησης. Το tailnet σας πρέπει να επιτρέπει το Funnel, που η Tailscale ακόμα χαρακτηρίζει beta. |

Όταν εκδίδεται πιστοποιητικό HTTPS για μια εφαρμογή, το όνομα συσκευής της στο Tailscale και το όνομα DNS του tailnet σας εμφανίζονται σε δημόσιο αρχείο καταγραφής πιστοποιητικών. Διαλέξτε ονόματα εφαρμογών που δεν σας πειράζει να τα δουν άλλοι.

## Γρήγορη εκκίνηση

Σε macOS και Linux, εγκαταστήστε με το Homebrew. Το εκτελέσιμο για macOS είναι υπογεγραμμένο με πιστοποιητικό Developer ID και επικυρωμένο (notarized) από την Apple. Για αναβάθμιση αργότερα, εκτελέστε `brew upgrade --cask tslink` και μετά ξανά `tslink install` αν το TSLink τρέχει ως υπηρεσία παρασκηνίου.

```bash
brew install --cask anydoor7/tap/tslink
```

Στα Windows, κατεβάστε το `tslink_<version>_windows_<arch>.zip` από την [τελευταία έκδοση](https://github.com/anydoor7/tslink/releases/latest), ελέγξτε το με το `checksums.txt` και εκτελέστε `tslink install` ώστε το TSLink να ξεκινά όταν συνδέεστε. Το zip δεν έχει υπογραφή Authenticode· [επαληθεύστε την έκδοση](verify-release.md) μέσω των υπογεγραμμένων αθροισμάτων ελέγχου και των βεβαιώσεων. Τα πακέτα `.deb` και `.rpm` για Linux βρίσκονται στην ίδια σελίδα έκδοσης. Για μεταγλώττιση από τον κώδικα χρειάζεστε **Git και Go 1.26.6+**. Οι εντολές παρακάτω χρησιμοποιούν bash/zsh· δείτε [Ρύθμιση macOS, Linux και Windows](platforms.md).

```bash
git clone https://github.com/anydoor7/tslink.git
cd tslink
go install .
export PATH="$PATH:$(go env GOPATH)/bin"
```

Χρειάζεστε **λογαριασμό Tailscale** και [MagicDNS και HTTPS](https://tailscale.com/docs/how-to/set-up-https-certificates). Οι συσκευές ιδιωτικής πρόσβασης χρειάζονται Tailscale και άδεια από την πολιτική δικτύου. Το TSLink ενσωματώνει το Tailscale στο μηχάνημα των εφαρμογών.

Αν η εφαρμογή εκτελείται ήδη στη θύρα 3000:

```bash
tslink share 3000 --name myapp
tslink url myapp --wait
```

Επιλέξτε ελεύθερο όνομα· αν το `share` επιστρέψει άλλο, χρησιμοποιήστε το στο `url`. Ολοκληρώστε πρώτα την εγγραφή στο πρόγραμμα περιήγησης και την έγκριση συσκευής που ζητούνται, έπειτα ανοίξτε το ακριβές URL από επιτρεπόμενη συσκευή. Το `share` ξεκινά την υπηρεσία παρασκηνίου όταν χρειάζεται. Η πρώτη ιδιωτική χρήση δεν απαιτεί διακριτικό API διαχειριστή. Μοιραστείτε αρχεία με `tslink share ./report.html`· πρέπει να υπάρχουν και οι εφαρμογές να εκτελούνται. [Πλήρης ρύθμιση](getting-started.md)

Όταν σας φανεί χρήσιμο στην πράξη, μπορείτε να [δώσετε ένα αστέρι στο TSLink](https://github.com/anydoor7/tslink), βοηθώντας άλλους να το βρουν. Είναι απολύτως προαιρετικό.

Σκεφτείτε μια ιδιωτική, κρυπτογραφημένη διαδρομή προς τις εφαρμογές σας. **Το Tailscale παρέχει μεταφορά δικτύου και HTTPS· το TSLink διαχειρίζεται την πρόσβαση ανά μηχάνημα.** Ένας δαίμονας εκτελεί ξεχωριστό ενσωματωμένο κόμβο ανά υπηρεσία. Η ιδιωτική πύλη δείχνει τις επιτρεπόμενες εφαρμογές· υγεία και ιστορικό βοηθούν στη συντήρηση.

Η δημόσια πρόσβαση ενεργοποιείται ρητά: οι επισκέπτες χρειάζονται σύνδεσμο και προαιρετικό PIN· το ανοιχτό Funnel είναι προσβάσιμο σε όποιον έχει το URL. Και τα δύο χρησιμοποιούν δημόσιο HTTPS, όχι ιδιωτική ταυτότητα χρήστη. Το απλό TCP παραμένει ιδιωτικό, με πολιτική tailnet και πιστοποίηση στο backend. Το TSLink δεν εγκαθιστά εφαρμογές, δεν απομονώνει διεργασίες, δεν δημιουργεί cloud VPC και δεν ενοποιεί πολλά μηχανήματα. Ανεξάρτητο έργο που συνεργάζεται με το Tailscale. [Αρχιτεκτονική και όρια](architecture.md)

## Για πράκτορες

Διαχειριστείτε κατάλογο, υγεία, URL και πρόσβαση μέσω CLI/MCP. Ξεκινήστε από τον [οδηγό πρακτόρων](agent-quickstart.md), διαβάστε τα τρέχοντα σχήματα εργαλείων και ελέγξτε την πραγματική πρόσβαση πριν αναφέρετε επιτυχία.

```json
{"mcpServers":{"tslink":{"command":"tslink","args":["mcp"]}}}
```

Η αυτοματοποίηση CLI χρησιμοποιεί `--json`· το MCP χρησιμοποιεί JSON-RPC μέσω stdio. [Πελάτες](mcp-clients.md) · [Απομακρυσμένο MCP](remote-mcp.md) · [Ρόλοι και όρια](mcp-scopes.md)
