<h1 align="center">TSLink</h1>
<p align="center">Το TSLink είναι ένα CLI και διακομιστής MCP ανοιχτού κώδικα που δίνει σε κάθε εφαρμογή του υπολογιστή σας μια ιδιωτική διεύθυνση <code>https://&lt;name&gt;.&lt;tailnet&gt;.ts.net</code>, ώστε εσείς ή ο coding agent σας να ανοίγετε στο κινητό έναν διακομιστή ανάπτυξης που τρέχει. Ανεξάρτητο έργο, δεν δημιουργήθηκε από την Tailscale.</p>
<p align="center">Το κινητό σας χρειάζεται την εφαρμογή Tailscale, συνδεδεμένη στο ίδιο tailnet.</p>
<p align="center"><strong>Ελληνικά</strong> · <a href="https://github.com/anydoor7/tslink">English</a> · <a href="README.zh-CN.md">简体中文</a> · <a href="README.ja.md">日本語</a> · <a href="README.ko.md">한국어</a> · <a href="README.es.md">Español</a> · <a href="INDEX.md#translated-homepages">Περισσότερες γλώσσες</a></p>

```text
# Claude Code, μετά την εγκατάσταση του CLI (δείτε την Εγκατάσταση παρακάτω)
/plugin marketplace add anydoor7/tslink
/plugin install tslink@tslink

# Τοπικοί πελάτες MCP που χρησιμοποιούν JSON με mcpServers (άλλοι: δείτε τη ρύθμιση MCP του πελάτη σας)
{"mcpServers":{"tslink":{"command":"tslink","args":["mcp"]}}}

Πείτε στον πράκτορά σας: "Μοιράσου τον διακομιστή ανάπτυξης για να τον ανοίξω στο κινητό μου."
```

Το ίδιο με το χέρι, με τον διακομιστή ανάπτυξης ήδη σε αναμονή στη θύρα 5173. Με το `--json`, το `share` αναφέρει το καταχωρισμένο όνομα στο `data.name`. Χρησιμοποιήστε αυτό το όνομα στις επόμενες εντολές: διαφέρει από το `--name` όταν εκείνο το όνομα ήταν πιασμένο, για παράδειγμα `web-2`.

```sh
tslink share 5173 --name web --json   # data.name· data.url, ή data.auth_url (σύνδεσμος σύνδεσης Tailscale) όταν το status είναι needs_login
tslink url <name> --wait              # αφού ολοκληρώσετε τη σύνδεση: το ακριβές URL
tslink remove <name>                  # όταν τελειώσετε· παραλείψτε το αν το share απέτυχε. Ο διακομιστής ανάπτυξης συνεχίζει να τρέχει
```

## Εγκατάσταση

Οι υπολογιστές macOS απαιτούν macOS 13 Ventura ή νεότερη έκδοση ([υποστηριζόμενες πλατφόρμες](platforms.md)).

```sh
brew install --cask anydoor7/tap/tslink
```

Στα Windows, εγκαταστήστε με Scoop:

```powershell
scoop bucket add anydoor7 https://github.com/anydoor7/scoop-bucket
scoop install anydoor7/tslink
```

Για αναβάθμιση, εκτελέστε `brew upgrade --cask tslink` ή `scoop update; scoop update tslink`. Αν το TSLink λειτουργεί ως υπηρεσία στο παρασκήνιο, εκτελέστε ξανά `tslink install` μετά την αναβάθμιση.

Τα πακέτα `.deb` και `.rpm` για Linux και οι εκδόσεις για Windows βρίσκονται στην [τελευταία έκδοση](https://github.com/anydoor7/tslink/releases/latest). Την πρώτη φορά που μοιράζεστε μια εφαρμογή, το TSLink εμφανίζει έναν σύνδεσμο εισόδου στο Tailscale για αυτήν. [Πρώτα βήματα](getting-started.md)

## Για πράκτορες AI

Έναν διακομιστή ανάπτυξης που ξεκινά ένας πράκτορας στο `localhost` δεν τον φτάνετε από το κινητό σας. Το TSLink επιτρέπει στον πράκτορα να του δώσει ιδιωτική διεύθυνση, να σας παραδώσει το ακριβές URL και να αφαιρέσει την κοινοποίηση όταν τελειώσει. Το κινητό σας χρειάζεται την εφαρμογή Tailscale, συνδεδεμένη στο ίδιο tailnet.

Δοκιμάστηκε στις 2026-10-22 με Vite 8.3.5 και iPhone 15 Pro: ο πράκτορας μοιράστηκε τον διακομιστή ανάπτυξης μέσω MCP, το κινητό άνοιξε το ιδιωτικό URL και η σελίδα ενημερώθηκε με την αποθήκευση χωρίς χειροκίνητη ανανέωση.

Για το Claude Code, εγκαταστήστε πρώτα το CLI και μετά εκτελέστε:

```text
/plugin marketplace add anydoor7/tslink
/plugin install tslink@tslink
```

Το πρόσθετο περιλαμβάνει ένα [skill προεπισκόπησης](../skills/tslink-preview/SKILL.md) και τη σύνδεση MCP παρακάτω. Το marketplace μένει σε αυτό το αποθετήριο και φέρνει το πρόσθετο από το [anydoor7/tslink-claude-plugin](https://github.com/anydoor7/tslink-claude-plugin). Το βασικό skill μένει εδώ· το πρόσθετο περιέχει ένα αντίγραφο που ελέγχεται από το CI. Άλλοι πράκτορες μπορούν να χρησιμοποιήσουν το ίδιο skill ή να συνδεθούν απευθείας μέσω MCP. Αυτή η ενσωμάτωση απαιτεί το τοπικό CLI και δεν λειτουργεί στη συνομιλία του claude.ai. [Ρύθμιση και εγγραφή](agent-integrations.md)

Για έναν τοπικό πελάτη MCP που χρησιμοποιεί JSON με `mcpServers` (άλλοι πελάτες: δείτε τις οδηγίες ρύθμισης MCP τους και τον [οδηγό πελατών MCP](mcp-clients.md)):

```json
{"mcpServers":{"tslink":{"command":"tslink","args":["mcp"]}}}
```

- **Πύλη από προεπιλογή στις νέες εγκαταστάσεις.** Κάθε ιδιωτική εφαρμογή HTTP/αρχείων αποκτά σταθερή θύρα, όπως `https://home.<tailnet>.ts.net:8443/`. Οι υπάρχουσες εγκαταστάσεις διατηρούν τη λειτουργία τους και οι εφαρμογές τους κόμβους/URL τους· το `--portal-only` επιλέγεται ρητά.
- **Εγγραφή της πύλης.** Χωρίς διαπιστευτήρια, ο επαληθευμένος λογαριασμός της ίδιας της πύλης χωρίς ετικέτες μπορεί να γίνει owner. Με tags/OAuth, εκτελέστε τοπικά `tslink portal enable --owner <login>`. Η εκκρεμής εγγραφή κόμβων εφαρμογών δεν εμποδίζει μια έτοιμη διαδρομή πύλης.
- **Πρόσβαση ανά άτομο.** Οι νέες εφαρμογές επιτρέπουν owner/admin και ρητά εξουσιοδοτημένα άτομα. Τα `people add`, `add --allow` και MCP `add/share.allow` ελέγχουν τη συμμετοχή και προετοιμάζουν τις αναγκαίες προσκλήσεις. Τα μέλη δεν χρειάζονται πρόσκληση συσκευής· οι εξωτερικοί χρήστες δέχονται μία πρόσκληση πύλης. Σφάλματα καταλόγου/API επιστρέφουν ημιτελή ρύθμιση.
- **Επεξεργάζεστε, αποθηκεύετε, βλέπετε.** Η αποθήκευση του κώδικα ενημερώνει τη σελίδα στο κινητό σας. Οι κανόνες Host και Origin της ίδιας της εφαρμογής σας μπορεί να μπλοκάρουν αιτήματα: στη δοκιμή μας το Vite δεν χρειάστηκε αλλαγή στο `allowedHosts`· το Next.js δεν έχει δοκιμαστεί και χρειάζεται ακόμη `allowedDevOrigins`.
- **Εκκαθάριση.** Ο πράκτορας καλεί το `unshare`, ή εσείς εκτελείτε `tslink remove <name>`, πάντα με το όνομα που επέστρεψε το αποτέλεσμα του share. Η αφαίρεση ακυρώνει την καταχώριση της κοινοποίησης και επιχειρεί να διαγράψει τον κόμβο της στο tailnet όταν το TSLink μπορεί να αποδείξει ότι τον κατέχει, γι' αυτό ελέγξτε στο αποτέλεσμα τα πεδία εκκαθάρισης ή διατηρημένης κατάστασης. Δεν σταματά τον διακομιστή ανάπτυξης.
- **CLI ή MCP.** Οι εντολές διαχείρισης δέχονται `--json` και επιστρέφουν αποτελέσματα με έκδοση. Το `tslink mcp` προσφέρει λειτουργίες εφαρμογών και πρόσβασης μέσω MCP.
- **Ένα αρχείο, όχι ο φάκελος.** Ένας πράκτορας μπορεί να μοιραστεί μόνο την αυτόνομη αναφορά HTML του με `tslink share ./report.html`. Τα άλλα αρχεία του φακέλου μένουν απρόσιτα.
- **Περιορισμένοι ρόλοι.** `viewer`, `app-operator` ή `people-manager`, μόνο για τις εφαρμογές που ορίζετε· για να μοιραστείτε μια νέα εφαρμογή χρειάζεται ο ρόλος `owner`. Το `tslink mcp-audit` δείχνει τι άλλαξε ένας πράκτορας. Οι ρόλοι περιορίζουν τα εργαλεία του TSLink, όχι το ίδιο το shell του πράκτορα.

<a id="why"></a>

## Πότε χρειάζεστε το TSLink

Για μία εφαρμογή που ξεκινάτε μόνοι σας και ανοίγετε στο δικό σας κινητό, αρκεί το Serve. Το TSLink είναι για τους διακομιστές ανάπτυξης που ξεκινά ένας πράκτορας, συχνά περισσότερους από έναν, όταν ο καθένας πρέπει να έχει δικό του ιδιωτικό όνομα και η κοινοποίηση, το URL και η εκκαθάριση να είναι έτοιμα βήματα στο CLI, στο MCP και σε ένα skill του Claude Code.

| Εργασία | Μόνο Tailscale | TSLink |
|---|---|---|
| Πολλοί διακομιστές ανάπτυξης που ξεκινά ο πράκτοράς σας, ένα όνομα ο καθένας | Το Serve ορίζει διαδρομές σε επίπεδο συσκευής κάτω από ένα όνομα ανά μηχάνημα· το Services απαιτεί για κάθε όνομα έναν ορισμό, μια έγκριση και έναν host με ετικέτες | Ένας κόμβος ανά εφαρμογή, με κοινοποίηση, αναζήτηση URL και εκκαθάριση έτοιμες στο CLI (`share`, `url`, `remove`), στο MCP (`share`, `url`, `unshare`) και σε ένα skill |
| Μία εφαρμογή που ξεκινάτε μόνοι σας, στο κινητό | Αρκεί το `tailscale serve 3000` | `tslink share 3000` |
| Ένα άτομο, μία εφαρμογή, επτά ημέρες | Κανόνες πολιτικής, μετά εργαλείο JIT ή χειροκίνητη αφαίρεση | `tslink people add alice@example.com --apps photos --for 7d` (HTTP/αρχεία) |
| Σύνδεσμος για περιηγητή, τρεις ημέρες | Δημόσιο Funnel, με δικό σας έλεγχο πρόσβασης και προγραμματισμένο τερματισμό | `tslink guest create photos --for 3d --public --print-link` (μόνο HTTP) |

Οι ιδιωτικοί παραλήπτες χρειάζονται Tailscale. Οι σύνδεσμοι επισκεπτών είναι δημόσιοι, μπορούν να προωθηθούν και λειτουργούν ως διαπιστευτήρια πρόσβασης.

<a id="use-cases"></a>

## Οι εφαρμογές σας, στις δικές σας συσκευές

- **Μια διεύθυνση για κάθε εφαρμογή.** Εφαρμογές web, φάκελοι, μεμονωμένα αρχεία και θύρες TCP παίρνουν το καθένα δικό του όνομα στο tailnet σας, οπότε χρησιμοποιείτε ονόματα αντί για διευθύνσεις IP.
- **Ιδιωτικό από προεπιλογή.** Τίποτα δεν γίνεται δημόσιο μέχρι να δημιουργήσετε σύνδεσμο επισκέπτη ή να δημοσιεύσετε μέσω Funnel.
- **Μία εφαρμογή, όχι όλο το μηχάνημα.** Κάθε εφαρμογή που δημοσιεύετε έχει δικό της κόμβο, που προωθεί μόνο σε αυτή την εφαρμογή. Χωρίς την εφαρμογή Tailscale στο μηχάνημα, το TSLink δεν προσθέτει άλλες θύρες του μηχανήματος στο tailnet σας.
- **Μια αρχική σελίδα** που δείχνει τις εφαρμογές σας με την κατάστασή τους. [Πύλη](portal.md)
- **Έλεγχοι υγείας και ειδοποιήσεις** μέσω εντολής ή webhook, και ένα αρχείο πρόσβασης που περιλαμβάνει τα αιτήματα που απορρίφθηκαν. [Υγεία και ειδοποιήσεις](health-and-alerts.md) · [Ιστορικό πρόσβασης](access-log.md)
- **Συνταγές για 15 αυτοφιλοξενούμενες εφαρμογές**, ανάμεσά τους Home Assistant, Jellyfin, Immich και Ollama. Το `tslink apps detect` βρίσκει όσες τρέχουν ήδη. [Συνταγές εφαρμογών](apps.md)

## Μοιραστείτε όταν θέλετε

```sh
tslink people add alice@example.com --apps notes --for 7d   # a tailnet member, for 7 days
tslink guest create notes --for 3d --public --print-link    # a browser link, no Tailscale needed
tslink add launch --proxy localhost:4000 --funnel --public --funnel-ttl 1h   # anyone, for one hour
```

Οι σύνδεσμοι επισκεπτών και τα νέα δημόσια URL λήγουν και λειτουργούν μόνο για εφαρμογές web. Φάκελοι, αρχεία και θύρες TCP μένουν ιδιωτικά. [Άτομα](people.md) · [Σύνδεσμοι επισκεπτών](guest-links.md) · [Δημόσια πρόσβαση](funnel.md)

Μία διεργασία παρασκηνίου τρέχει ξεχωριστό κόμβο Tailscale για κάθε εφαρμογή. Το Tailscale παρέχει τη μεταφορά μέσα στο tailnet και τα πιστοποιητικά HTTPS. Η ιδιωτική πρόσβαση σε web και αρχεία μπορεί να περιοριστεί ανά ταυτότητα Tailscale με `--allow` και άδειες ανά άτομο. Το σκέτο TCP βασίζεται στην πολιτική του tailnet σας και στη σύνδεση της ίδιας της εφαρμογής. [Αρχιτεκτονική](architecture.md)

<a id="requirements"></a>

## Απαιτήσεις

| Ποιος | Χρειάζεται |
|---|---|
| Εσείς | Λογαριασμό Tailscale με ενεργά MagicDNS και HTTPS |
| Το μηχάνημα που τρέχει τις εφαρμογές σας | Το TSLink, που ενσωματώνει το Tailscale (στο Linux, μια συνεδρία χρήστη systemd) |
| Οι συσκευές σας και τα άτομα με τα οποία μοιράζεστε εφαρμογές | Την εφαρμογή Tailscale |
| Επισκέπτες | Έναν περιηγητή |

Τα ονόματα των εφαρμογών HTTPS εμφανίζονται σε δημόσια αρχεία καταγραφής πιστοποιητικών, οπότε διαλέξτε ονόματα που δεν σας πειράζει να δουν άλλοι.
